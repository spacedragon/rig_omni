# RIG-Hover 换装 M5Stack StopWatch：设计方案

> **状态：概念设计，未经实物验证。** 版本 D，2026-11-13。
> 本文只记录设计决定和依据，仓库里还没有对应的固件代码。

用 M5Stack StopWatch 取代 RIG-Hover 的原装主控板和屏幕，摄像头改用 AtomS3R-M12，整机外壳重新设计。

## 1. 方案总览

- **单主控**：平衡控制、语音、表情、联网都在 StopWatch 上。
- **独立摄像头**：AtomS3R-M12 自带 ESP32-S3，负责拍照和 JPEG 压缩，通过串口把照片交给 StopWatch。
- **底盘无单片机**：只有两个轮毂电机、头部舵机、2S 电池和一块供电板。
- **造型沿用原项目**：圆头、细颈、两个大轮夹着底盘。摄像头做成头顶的小舱。

## 2. 硬件对比

| 项目 | RIG-Hover 原装 | 本方案 | 影响 |
|------|----------------|--------|------|
| 主控 | ESP32-S3-WROOM-1-N16R8 | StopWatch：ESP32-S3R8，16MB Flash，8MB PSRAM | 同档，分区和 PSRAM 配置可沿用 |
| 屏幕 | 1.09" GC9A01，SPI，240×240 | 1.75" 圆形 AMOLED，CO5300，QSPI，466×466 | 换驱动，表情素材要处理 |
| 姿态传感器 | QMI8658C | StopWatch 内置 BMI270 | 换驱动，重新对轴向 |
| 音频 | INMP441 + MAX98357A，无 codec | ES8311 + AW8737A | 换成 codec 方案 |
| 摄像头 | GC0308，DVP 并口 | AtomS3R-M12（OV3660，300 万像素，视场角 120°） | 改为串口取图 |
| 电池电量 | 读舵机 ID 3 的电压寄存器 | 不变 | 不需要额外的 ADC 分压 |

StopWatch 引脚和规格来自 <https://docs.m5stack.com/en/core/StopWatch>，AtomS3R-M12 来自 <https://docs.m5stack.com/en/core/AtomS3R-M12>。

## 3. 电气设计

### 3.1 接线

```
机身                                    颈部 4 芯            头部
2S 电池 ──7.4V──┬── 左轮 KP4012 (ID 1)
                ├── 右轮 KP4012 (ID 2)
                ├── 头部舵机 EM3 (ID 3)
                └── 降压 ──5V────────────── 5V ──────┬── StopWatch (USB-C 输入)
                                                     └── AtomS3R-M12 (Grove 5V)
三个电机 ──总线── 收发合并 ──────────────── 发送 ───── StopWatch G10
                                 ────────── 接收 ───── StopWatch G11
公共地 ─────────────────────────────────── 地
                                                     StopWatch G3 → AtomS3R-M12 G1
                                                     StopWatch G4 ← AtomS3R-M12 G2
```

- 电机总线：UART，1 Mbps。原固件用 UART2，TX 为 GPIO 46、RX 为 GPIO 38，见 [hover_board.cc](../../../main/boards/hover/hover_board.cc) 的 `InitializeUart()`。这两个脚在 StopWatch 上是屏幕的 D2 和 TE，所以改到 Grove 口的 G10、G11。
- StopWatch 的 Grove 口只用 G10、G11 和地。它的 5V 脚是对外输出，不接到 5V 电源上。
- StopWatch 的 5V 从 USB-C 口输入，避开背面排针 5V 脚的版本差异（见第 7 节）。

### 3.2 StopWatch 引脚分配

| 用途 | 引脚 | 接到 | 说明 |
|------|------|------|------|
| 电机总线发送 | G10（Grove） | 收发合并电路 | 原固件为 GPIO 46 |
| 电机总线接收 | G11（Grove） | 收发合并电路 | 原固件为 GPIO 38 |
| 摄像头串口发送 | G3（背面排针） | AtomS3R-M12 的 G1 | 发拍照和休眠命令 |
| 摄像头串口接收 | G4（背面排针） | AtomS3R-M12 的 G2 | 收 JPEG 数据 |
| 对话键 | G2（黄键） | 板载 | 替代原来的 BOOT 键 |
| 动作键 | G1（蓝键） | 板载 | 替代原来的 GPIO 3 触摸键 |
| 备用 | G5 – G9 | 未接 | |

StopWatch 板载外设占用的引脚（不可改）：

| 外设 | 引脚 |
|------|------|
| 屏幕 QSPI | CS 39，SCK 40，D0–D3 为 41 / 42 / 46 / 45，TE 38；复位在 M5IOE1 的 PYG5 |
| I2C 总线 | SDA 47，SCL 48 |
| I2C 设备 | BMI270（0x68），ES8311（0x18），M5IOE1（0x4F），RX8130CE（0x32），M5PM1，触摸 CST820B |
| I2S | MCLK 18，BCLK 17，LRCK 15，codec 输出 16，codec 输入 21 |
| 经 M5IOE1 控制 | 屏幕供电 PYG8，屏幕复位 PYG5，触摸复位 PYG4，音频供电 PYG3，功放使能 PYG10 |

### 3.3 供电

| 负载 | 电压 | 预留电流 | 依据 |
|------|------|----------|------|
| StopWatch | 5 V | 1 A | 估算，含内置电池充电最高 425 mA |
| AtomS3R-M12 | 5 V | 0.5 A | 估算，官方未给工作电流 |
| 降压模块选型 | 7.4 V → 5 V | ≥ 2 A | 留余量 |
| 两个轮毂电机和头部舵机 | 7.4 V 直供 | 未定 | 缺电机数据 |

供电板集成三样东西：2S 充电与保护、7.4 V 转 5 V 降压、总线收发合并。

## 4. 摄像头方案

原机的 GC0308 是 DVP 并口，至少要 12 根信号线。StopWatch 背面排针只有 G3 到 G9 共 7 个 GPIO，接不了。

改用 AtomS3R-M12，一根 4 芯线连接：5V、地、TX、RX。

- 选串口而不是 Wi-Fi：摄像头不用单独配网，StopWatch 可以直接命令它休眠。
- 代价：按 921600 波特率，一张约 30 KB 的 VGA JPEG 传输约 0.3 秒。拍照问答够用，做不了流畅的实时预览。
- 固件影响：摄像头只被 `self.camera.take_photo` 和 `self.camera.preview` 两个工具使用（[mcp_server.cc](../../../main/mcp_server.cc)）。第一版只支持拍照，不支持预览。

## 5. 结构设计

单位 mm。

| 项目 | 原机 | 本设计 |
|------|------|--------|
| 总高 | 139 | 192 |
| 总宽 | 约 61 | 90（轮外侧） |
| 头壳 | 无资料 | Ø80 × 深 40 的圆鼓 |
| 摄像头舱 | 无 | 32 × 28 × 30，在头顶，下沿沉入头壳 4 |
| 轮径 | 无资料 | 70（自制轮圈套在轮毂电机外） |
| 底盘内腔 | 无资料 | 54 × 50，高 68 |
| 电池舱 | 装 500 mAh | 50 × 40 × 25，可换 1000 mAh 级 |

布局从下到上：电池、供电板、头部舵机（都在两轮之间的底盘内），10 高的细颈，圆形头部，头顶摄像头舱。

- **头部**：StopWatch（Ø52 × 15.5）嵌在头壳正面中心，表面与头壳齐平，背后有约 22 的空间放 USB-C 弯头、线束和出音腔。
- **头部转动**：绕竖直轴 ±75°，扫掠直径约 89。头壳在轮子上方的最小间隙约 30，不干涉。
- **姿态传感器必须在头部**：[imu.cc](../../../main/boards/common/imu.cc) 用头部转角 `q_head` 旋转陀螺仪和加速度计读数来计算俯仰角。StopWatch 装在头部时，内置 BMI270 的位置和原机等价。
- **颈部线束**：4 芯（5V、地、总线发送、总线接收）。

仓库里没有原机的机械资料，下面的值是为了画出比例设的，到货后要实测。

| 零件 | 图中取值 | 需要量的尺寸 |
|------|----------|--------------|
| 轮毂电机 KP4012 | Ø40 × 12 | 外径、厚度、固定孔位、出线位置 |
| 自制轮圈加轮胎 | Ø70 × 16 | 由电机外径和力矩决定上限 |
| 头部舵机 EM3 | 23 × 12 × 23 | 外形、输出轴位置、安装耳 |
| 供电板 | 46 × 50 × 4 | 由降压模块和充电方案决定 |

## 6. 固件移植清单

做法：新建一个板型（复制 `main/boards/hover/`），不改现有四个板型的行为。[tools/create_board.py](../../../tools/create_board.py) 有 Hover 模板（`em3_kp4012`）。

| 项目 | 要做的事 | 现状 |
|------|----------|------|
| 板型注册 | Kconfig 的 `BOARD_TYPE` 选项和所有 `depends on`；CMake 的 `rig_board()`；[system_info.cc](../../../main/system_info.cc) 里三处板型判断 | 未做 |
| M5PM1 / M5IOE1 | 写驱动。开机先开屏幕供电、放开屏幕和触摸复位、开音频供电和功放 | 仓库里没有；可参考 `m5stack/M5StopWatch-UserDemo`（ESP-IDF） |
| 屏幕 | CO5300 QSPI | [idf_component.yml](../../../main/idf_component.yml) 已有 `espressif/esp_lcd_co5300` |
| 表情素材 | CMake 里分辨率写死为 `240_240`，EAF 素材也是 240×240。先居中显示，后续重做素材 | 表情引擎能否放大未核实 |
| 音频 | ES8311 codec，功放使能经 M5IOE1 | 已有 [es8311_audio_codec.cc](../../../main/audio/codecs/es8311_audio_codec.cc) |
| 姿态传感器 | BMI270 实现，输出与现有 `imu.cc` 同名的变量；和 codec、扩展芯片共用一个 I2C 总线句柄 | [idf_component.yml](../../../main/idf_component.yml) 已有 `espressif/bmi270_sensor`；`imu.cc` 是共享文件，要用条件编译隔开 |
| 电机总线 | 只改 `board_config.h` 里的 TX / RX 引脚 | 协议代码不变 |
| 按键 | BOOT 键改 G2，触摸键改 G1 | |
| 摄像头 | 去掉 DVP 初始化；新增一个通过串口取图的 `Camera` 实现 | AtomS3R-M12 侧也要一个小固件 |

风险最大的一项是 I2C 争用：原固件的姿态任务每 2 ms 读一次，而 StopWatch 上姿态传感器和 codec、触摸、电源芯片共用一条总线。

另外注意 [config.h](../../../main/boards/common/config.h) 里 `USE_HARDCODED_WIFI` 为 1，写死了厂商的 Wi-Fi，自用时要改成 0。

## 7. 待确认事项

1. **总线是单线还是双线。** 飞特系舵机通常是单线半双工，所以方案里有收发合并电路。拿到电机后看线是 3 根还是 4 根。
2. **总线逻辑电平。** StopWatch 是 3.3 V 引脚。电机信号线如果是 5 V 电平，合并电路里要带电平转换。
3. **StopWatch 的版本。** v1.0 机身贴纸上标 BAT 的脚实际是 5V 输入，v1.0.1 才改对。本方案从 USB-C 口供电，不受影响。
4. **电机力矩够不够带 70 的轮子。** 轮径加大后同样力矩产生的驱动力变小，而机身更高更重。KP4012 的额定力矩没有数据，要实测；不够就把轮径收小。
5. **电机和舵机的实物尺寸。** 见 5.1 节。
6. **USB-C 插头的空间。** StopWatch 的 USB-C 口位置未核实，需要弯头线或在外壳上让位。
7. **平衡参数重调。** 头部比原机重约 50 g 且更高，重心上移。调参顺序按官方说明：`imu_zero`，然后 LQR 的 k2、k3、k1、k0，最后 `k_yaw`。

## 8. 建议的实施顺序

1. 不动结构：StopWatch 用自带电池供电，只接 UART 和共地，跑通电机和舵机的读写。
2. 移植屏幕、音频、姿态传感器，让语音和表情先工作。
3. 做供电板，打印外壳，装机。
4. 调平衡。
5. 加摄像头。
